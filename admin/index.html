Google Authentication Setup

To enable 1-click Google Sign-In for Ishaan, add your Google OAuth Web Client ID to .env.

1

Open Google Cloud Console → Credentials (or your Firebase Console → Authentication).

2

Create or copy an OAuth 2.0 Web Client ID.

3

Add http://localhost:5173 to Authorized JavaScript origins.

4

Paste the Client ID into .env in your project root:

VITE_GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com

Once saved in .env, refresh this page to sign in immediately.
